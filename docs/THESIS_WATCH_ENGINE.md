# Emerging Thesis Watch Engine

Kong and GME now prove a small shared architecture. They do not share a forced domain model or identical interface.

## Proven common infrastructure

- a static Site shell that reads canonical public JSON at run time;
- deployment snapshots for safe fallback;
- explicit source provenance and freshness;
- split material-event records plus compact indexes;
- historical state that is not rewritten by later knowledge;
- deterministic validation before publication;
- visible degraded behavior instead of missing-as-normal;
- stable routes within one Site project.

## Domain-specific behavior

Kong remains an IPO valuation and evidence-compass product. Its scenario model, thesis score, IPO milestones, and private-company disclosure gaps are Kong-specific.

GME remains a market-mechanism monitor. Its six engines, evidence-gated state machine, options and capital-structure maps, competing explanations, and negative controls are GME-specific. GME intentionally has no numerical squeeze score.

## Minimal Watch contract

A future Watch may define its own interface and state semantics, but should provide:

- a falsifiable thesis;
- causal drivers and counterforces;
- observations with provider, observed time, effective time, freshness, and limitation;
- deterministic derived metrics where possible;
- explicit inference boundaries;
- state-transition gates;
- catalysts and falsifiers;
- immutable history and material events;
- update health and safe fallback behavior.

Extraction stops here. A generic rendering framework or universal scoring model is not yet justified by two deliberately different Watches.
