# Kong IPO Compass Build Plan

Last updated: 2026-09-03

This is the human-readable product roadmap and decision history. Git/GitHub and hosting reality are authoritative for operational facts. Agents reconcile this document; the product owner does not maintain it manually.

## Product north star

Turn an uncertain private-company outcome into a legible, adjustable decision model: show the current Kong IPO thesis, expose the assumptions that move the implied share price, and translate each scenario into the user's personal holding value without confusing estimates for facts.

- Production: https://vita-learning-atlas.viet591697.chatgpt.site (version 3 live)
- Candidate: none
- Current wave: V0.2 live-data architecture
